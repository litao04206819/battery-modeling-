# battery-modeling-

A coupled **Battery → Motor → Rotor** system model for multirotor / eVTOL
propulsion, built around a high-fidelity PyBaMM **Doyle–Fuller–Newman (DFN)**
lithium-ion cell model.

The battery is driven by a **power/current demand profile** generated by a
high-fidelity rotor (blade-element momentum theory) and motor (PMSM dq-axis)
model. An optional bus-voltage feedback loop closes the coupling so the
battery's voltage sag feeds back into the motor current draw.

```
mission profile ─► [Rotor BEMT] ─►(T,Q,Ω)─► [Motor PMSM] ─►(P_dc, I_dc)─► [Battery DFN+thermal+ageing]
                                                  ▲                                │
                                                  └────────  bus voltage  ◄────────┘   (optional feedback)
```

## Subsystems

| Subsystem | Module | Fidelity |
|-----------|--------|----------|
| Battery   | `bmr.battery` | PyBaMM DFN + lumped thermal + coupled SEI/plating/cracking/LAM ageing |
| Motor     | `bmr.motor`   | PMSM dq-axis steady state, copper + iron + mechanical losses |
| Rotor     | `bmr.rotor`   | BEMT with Prandtl tip loss, analytic aerofoil polar |
| Airframe  | `bmr.aircraft`| weight → per-rotor thrust trim |
| Mission   | `bmr.mission` | segment-based profile (hover/climb/cruise/descend) |
| Coupling  | `bmr.coupling`| profile builder (1-way) + bus-voltage feedback (closed-loop) |

## Install

```bash
python -m pip install -r requirements.txt
# or, as an editable package:
python -m pip install -e .
```

PyBaMM ≥ 24.5 is required (provides `pybamm.step.power`, `IDAKLUSolver`, and the
`"Voltage [V]"` output naming used here). Developed/verified against PyBaMM 26.x.

## Quick start

```bash
# Stage 1 — battery alone, synthetic power profile
python scripts/run_battery_only.py

# Stage 2 — rotor + motor demand profile (+ hover sanity check)
python scripts/run_motor_rotor.py

# Stage 3 — full coupled system over the mission
python scripts/run_full_system.py --mode profile     # one-directional (fast)
python scripts/run_full_system.py --mode feedback    # bus-voltage feedback
```

Results (CSV + PNG) are written to `data/results/`.

## Configuration

All physical parameters live in `configs/`:

- `battery.yaml` — DFN preset (`high_rate_thermal` vs `life_degradation`),
  parameter set, thermal/ageing options, pack series/parallel topology.
- `motor.yaml` — PMSM electrical + loss parameters.
- `rotor.yaml` — propeller geometry, twist/chord, aerofoil polar.
- `aircraft.yaml` — mass, rotor count, air density, nominal bus voltage.
- `mission_*.yaml` — flight segments and time step.

### Battery presets

- **`high_rate_thermal`** — `Chen2020` (or `ORegan2022`) + lumped thermal. For
  hover/climb high-C-rate thermal performance.
- **`life_degradation`** — `OKane2022` + SEI growth, lithium plating, particle
  cracking and loss of active material. For mission-life / ageing studies.
